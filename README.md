# 🎮 Rock Paper Scissors

A simple **Rock Paper Scissors game built in C++** as a practice project for applying fundamental C++ programming and Object-Oriented Programming concepts.

## 📌 About the Project

This project recreates the classic Rock Paper Scissors game where the player competes against the computer.

The project was created to practice writing structured C++ code, handling user input, applying game logic, and working with programming concepts learned during university coursework.

## ✨ Features

* 🎮 Player vs Computer gameplay
* ✊ Rock, 📄 Paper, and ✂️ Scissors choices
* 🤖 Computer-generated choice
* 🏆 Win, lose, and draw detection
* 🔄 Simple interactive gameplay
* 📊 Game result display

## 🧠 Concepts Practiced

* C++ fundamentals
* Variables and data types
* Conditional statements
* Functions
* User input and output
* Random number generation
* Game logic
* Object-Oriented Programming concepts
* Basic code organization

## ⚙️ How It Works

1. The player selects **Rock, Paper, or Scissors**.
2. The computer makes its choice.
3. The program compares both choices.
4. The winner is determined according to the rules:

   * Rock beats Scissors
   * Scissors beats Paper
   * Paper beats Rock
   * Same choices result in a draw
5. The result is displayed to the player.
